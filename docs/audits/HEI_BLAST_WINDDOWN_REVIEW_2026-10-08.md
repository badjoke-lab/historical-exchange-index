# HEI Blast wind-down review — 2026-10-08

Blast announced on 2026-10-02 that the L2 will wind down and asked users to withdraw assets to Ethereum.

## Canonical event updates
- BladeSwap: chain_shutdown_impact added; no death date inferred.
- BlasterSwap: chain_shutdown_impact added; no death date inferred.
- Blitz Exchange: chain_shutdown_impact added; existing inactive status retained.

## Reviewed without entity-level status change
- Fenix Finance: already inactive before the Blast announcement.
- Baseline: continuing entity across later Base generations.
- DyorSwap, Ambient, SushiSwap, DackieSwap, Archly: multichain entities; Blast is not the whole entity.
- HyperBlast: current HEI evidence does not establish enough Blast-chain lineage to assign this event solely from the name.

The 2026-10-26 normal-interface deadline is not treated as a universal asset-loss deadline or an exchange death date. Blast stated that withdrawals remain possible afterward through bridge contracts on Ethereum L1.
